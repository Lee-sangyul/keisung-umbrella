보관 위치 일괄 지정

등록된 우산 ID 범위(최대 500개)의 보관 위치를 설정합니다. 다른 우산 상태는 변경되지 않습니다.

기존 우산은 기본적으로 ‘미지정’ 위치입니다. 장소별 실사는 우산의 위치를 먼저 지정해야 정확한 미확인 목록을 만들 수 있어요.

새 재고 실사 시작

실사 시작 시점의 대여 가능·파손 우산을 확인 대상에 고정합니다. 대여 중·분실·폐기 우산은 제외합니다.

실사는 시스템상의 우산 상태를 자동 변경하지 않습니다. 미확인 우산은 실제 대여 기록과 위치를 확인한 후 관리자가 따로 처리해야 해요.

학생 PIN 상태 및 재발급

PIN 상태 확인 중

PIN이 없는 학생은 키오스크에서 직접 PIN을 만들 수 있습니다. PIN을 잊었을 때만 담당 교사가 신원을 확인한 후 재발급해 주세요.

학생 PIN 최초 등록은 바로 적용됩니다. 학년·반·번호만으로 다른 학생의 PIN을 선점할 수 있으므로 학교 운영 전에 본인 확인 대책을 마련해야 합니다.

예외 대여가 필요한 학생은 담당 교사 확인 후 이번 달에만 추가 횟수를 설정하세요.

패널티 기록 추가

패널티 1점은 부여한 달의 대여 가능 횟수 1회를 차감합니다. 다음 달에는 재차 차감하지 않으며, 취소하면 해당 달의 차감도 복구됩니다. 학생의 책임이 확인되지 않은 파손에는 점수를 부여하지 마세요.
